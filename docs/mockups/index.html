Loop Dashboard

Three design directions.

Same three screens, same real data, three different personalities. Pick the one that feels least like a template — then it gets built for real across all nine tabs.

Instrument

No cards at all. Structure from hairline rules and column alignment; monospace tabular numerals so figures lock into columns. One element per screen is 5–10× everything else. Sodium-amber signal colour on warm near-black — a lit instrument, not a dark-mode SaaS app.

Editorial

Dramatic hierarchy. One dominant figure or headline per screen, everything else deliberately quiet. Spacious at the top, dense as you scroll. Reads like a printed research report rather than a dashboard.

Blueprint

Leans into what the product actually is — a pipeline. Technical-drawing aesthetic with a faint grid substrate and labelled connectors; the flow from proposal to merged PR is visible on every screen, and an item's stage is its status.
