### Hour 0:15–0:45 — AGENT: make the AWS bullet true
```bash
EMBEDDING_BACKEND=bedrock node scripts/ml/build-index.mjs   # → data/embeddings-titan.json
node scripts/ml/evaluate.mjs

```
Titan Text Embeddings V2 needs **no use-case form** — that form is Anthropic-specific, and
Amazon's own models aren't sold through AWS Marketplace. Cost: about half a cent.

**Even with zero labels this produces a real result:** Spearman rank correlation and top-k
Jaccard between MiniLM and Titan. A genuine two-encoder comparison, no labelling required.

### Hour 0:15–1:15 — OWNER, in parallel: label the gold set
```bash
cp data/gold-pairs-unlabeled.jsonl data/gold-pairs.jsonl
# fill "label" on each row: duplicate | related | unrelated
```
**40–60 rows is enough.** Start at the `lex_top` and `dense_top` strata — the hard cases where
methods disagree carry the most information per label. Wider confidence intervals are the honest
outcome at small n, and reporting the interval instead of the point estimate is the correct move.

Without labels: you have a *harness*. With labels: you have a *result*.

### Hour 1:15–1:45 — AGENT: the real comparison
Re-run `evaluate.mjs` on the labelled set. Output: lexical overlap vs BM25 vs MiniLM vs Titan,
precision/recall at a swept threshold, with bootstrap CIs. **Expect overlapping intervals — say
so rather than claiming a winner.**

### Hour 1:45–2:15 — AGENT: docs + push
Update `docs/ml-dedup.md` with the measured result, write the resume bullets from what actually
ran, push the commits.

### Hour 2:15–4:30 — STRETCH ONLY: ECS deploy
Attempt **only** if everything above is done. Four known traps:
- `docker build --platform linux/amd64` — Apple Silicon vs Express Mode's x86_64. A mismatch
  crash-loops **and Express auto-rolls-back, hiding the evidence.**
- `--health-check-path /api/health` — the default hits `/`, gets 307'd to `/login`, never healthy.
- Pin `maxTaskCount: 1` — default is 20; six in-memory stores assume one process.
- `deploy.yml` calls `aws ecs update-service`; Express needs `update-express-gateway-service`.

**If it isn't working by hour 4, stop.** Bedrock already gives you AWS on the resume.
